- 업데이트: `npm run build:pages` 후 docs 폴더를 포함해 커밋하면 Pages가 다시 배포합니다.

- 매물 수정은 각 브라우저에만 저장되며 방문자 간 공유되지 않습니다.

# 1등자이부동산 · 동대문 인사이트

동대문구 아파트 시장 브리핑용 반응형 대시보드입니다. 전용 건축 모티프 SVG 로고, 네이비·블루 팔레트, 출력 스타일을 포함합니다.

## 실행

Node.js 22 이상에서 `npm run dev` 후 http://127.0.0.1:4173 에 접속합니다. 외부 패키지 설치는 필요하지 않습니다. 실제 조회는 `.env.example`의 변수명을 사용해 서버 환경에 키를 설정해야 합니다. 키는 소스·브라우저에 포함하지 않습니다. 배포 서버에는 Sites 비밀 환경변수로 설정했습니다.

`npm test`: XML 파싱, 금액·날짜 정규화, 전세·월세 구분, 취소 거래, 조회 입력 검증. `npm run build`: Cloudflare Worker 출력.

## 사용

- 동 선택, 주간/월간, 시작일·종료일을 지정하고 데이터 조회. 최대 1년이며 월 단위 원본을 불러와 정확한 계약일로 필터링합니다.
- 매매·전세: 단지별 최고 거래금액 Top 10. 월세: 월세 높은 순, 같으면 보증금 높은 순. 면적을 통제한 순위는 아닙니다.
- 지도·순위·전체 목록·추천 매물 선택은 동일 입지 분석과 거래 이력을 갱신합니다. 지도 전체 보기로 Top 10 위치를 다시 확인합니다.
- 전체 목록은 **조회 기간 거래가 있는 단지 전체**입니다. 무거래 단지를 포함하는 동대문구 단지 등록부는 아닙니다. 샘플은 24개 단지입니다.
- 추천 매물 4건은 시연용 가상 매물. 등록·수정·삭제는 **현재 브라우저 localStorage**에만 저장됩니다. 기기 간 공유·서버 동기화는 없습니다.
- 한국부동산원은 동대문구 공식 월간 매매가격지수를 자동 조회합니다. 다른 통계는 접이식 메뉴의 공식 통계표/항목 목록에서 지역·항목 코드를 입력해 조회합니다. 임의 코드로 공식 지수를 생성하지 않습니다. 목록은 첫 1,000건, 지표 최대 1,000건입니다.
- 브리핑 출력은 브라우저 인쇄/PDF 저장을 사용합니다.

## 데이터 범위와 제한

국토교통부 API: 법정동 지역코드 `11230`, 아파트 매매 상세 및 전월세 API. 매매 취소 거래를 제외합니다. API 활용신청 승인은 각 서비스별로 필요할 수 있습니다. 조회 실패시 화면 상단과 각 지표에 샘플임을 표시한 가상 데이터로 시연합니다. 빈 실제 조회 결과는 샘플로 대체하지 않습니다. 실제 조회를 다시 하려면 데이터 조회 버튼을 누릅니다.

단지 좌표는 OpenStreetMap 이름 매칭 좌표 또는 자체 등록 참고 좌표로 정밀 측량·공식 지오코딩 결과가 아닙니다. 좌표 미등록 단지는 잘못된 마커 대신 지도 검색 링크를 제공합니다. 배경 지도는 Leaflet 및 OpenStreetMap CDN과 타일 연결이 필요합니다.

입지 정보는 생활권 단위 참고 설명이며, 거리·학군 배정·최신 개발사업 단계에 대한 실시간 검증 자료가 아닙니다. 학교/상권/교통의 지도 검색과 서울시 정비사업 원문 링크를 제공합니다. 정확한 POI 좌표나 학교별 도보 거리는 별도 데이터 연계가 필요합니다.

10년 전망은 현재=100으로 연복리 계산한 **가정 시나리오**입니다. 연간 변동률 조절 가능, 기준 ±2%p 경로 표시. 실제 통계에 학습한 예측이나 투자 수익 보장이 아닙니다.

실제 매물의 공개 광고에는 중개사무소 등록번호·주소·대표자, 매물 필수 광고사항 등을 운영자가 확인·보완해야 합니다. GitHub Pages 공개 화면은 기존 공개 API 서버에 연결합니다. API 키는 서버 비밀 환경변수에만 보관하며 GitHub 소스와 Pages 파일에 포함하지 않습니다.

## 검증 상태

서버 처리 테스트 3건 및 JS 구문 검사 통과. 배포 환경에서 로그인·화면·지도 표시와 국토교통부 매매(2026-11-01~13, 19건), 전세 실거래 수신을 확인했습니다. 한국부동산원 공식 통계표와 동대문구 월간 매매가격지수(A_2024_00045, 지역 530017, 항목 100001)의 2026년 1~9월 응답을 확인했습니다. 공식 지수는 상단 선택 기간과 별도로 최근 공표 12개 시점을 보여줍니다. OSM 주변시설·단지 1,984건을 2026-11-13 공개 자료 스냅샷으로 포함합니다. 시설 자료는 완전하지 않으며 실시간 갱신이 아닙니다.
